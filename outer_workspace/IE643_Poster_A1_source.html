Abstract

Text, sketch and reference image can disagree about the same object. We study an Attribute Routing Layer (ARL) that gives each modality an explicit job: text = identity, sketch = shape, reference = colour and material. The ARL is meant to sit between the three conditioning signals and a frozen SDXL + ControlNet + IP-Adapter backbone.

We tested routing variants on a 200-photo Sketchy conflict set. Detecting conflicts and rescaling global strengths did not enforce attribute control. A simple neutral-caption intervention improved object compliance and sketch fidelity, but not colour or material.

Introduction

  • One generation receives textsketchreference at once, and they can conflict: the caption says purple, the reference is silver.
  • Without a rule the strongest pathway wins; a reference also carries its own object shape.
  • Giving each modality a separate attribute responsibility makes the conflict well-posed and the result measurable per attribute.
text: identity sketch: shape reference: colour + material
Rule: where inputs conflict, the reference wins colour

Main Contributions

  • Three-modality attribute-routing formulation: each attribute has exactly one governing modality.
  • Attribute Routing Layer architecture that directs identity, geometry and appearance to separate conditioning pathways of SDXL.
  • Conflict-oriented dataset: Sketchy-based, with object, colour, material and swapped-reference conflict rows.
  • Experiments on attribute-level control, including negative results, with attribute-wise compliance metrics.

Methodology

  • Backbone: frozen SDXL, scribble ControlNet (sketch), IP-Adapter ViT-H (reference).
  • Router: reads the three inputs and decides, per attribute, which pathway may carry it.
  • Conditioning pathways: text cross-attention (identity), ControlNet residuals (geometry), IP-Adapter tokens (colour, material).
  • Intervention tested: neutral caption (colour words become "colored", material words "solid") plus a higher IP-Adapter scale.

Dataset Details

  • Source: Sketchy sketch-photo pairs; ~200 selected photos, one object each.
  • Per example: photo, sketch, caption (Qwen3-VL-2B), neutral-object reference carrying the photo's colour, material and finish.
  • Conflict cases: object, colour, material, swapped reference (rows built from metadata).

Conclusion

  • Explicit attribute responsibilities (text = identity, sketch = shape, reference = colour and material) make multimodal conflicts well-defined and measurable.
  • Global conditioning cannot enforce them: flags and strengths changed little in the output.
  • Reliable attribute-level control with a trained ARL remains open.
