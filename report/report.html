IE 643 Novelty Assessment Report

Constraint-Driven Multimodal Diffusion using Text, Sketch and Reference Image
Team One Sheep Army · R. Harshitha (24B0053)

1. Starting point: the intensive-assessment submission

For the intensive assessment we proposed attribute routing: sketch → geometry, text → semantics, reference → appearance. The planned FLUX.1-dev + UniCombine backbone ran out of memory on the free T4, so we submitted a frozen SDXL + scribble ControlNet + IP-Adapter pipeline on a 200-photo Sketchy pilot (160/20/20 split by photo; captions by Qwen3-VL-2B; neutral-object reference images v2; 800 labelled conflict rows: object, colour, material, swapped reference). Its "routing" was a small MLP (six CLIP cosines → four global scalars: sketch strength, sketch hold time, reference strength, text guidance) trained on 28 items × 9 generated variants, compared against fixed and hand-scheduled weights, with optional constraint guidance. Findings of that submission:

  • Fixed weights gave the best edge precision; the router's caption-alignment gain over the schedule was not significant; constraint guidance improved colour match by 0.042 but cut edge precision by 0.085.
  • The conflict features could not separate conflict types (colour 0.610, material 0.541, swapped reference 0.597 vs normal 0.604), so the router's outputs barely varied and it behaved like the hand schedule. The reference also copied its own object (DINO to reference 0.673 vs 0.105 to the target).
  • Two parameter values on the slides were wrong: the code used guidance weight 0.25 and relax 0.3, not 0.03 and 0.7.

Novelty goal. The course brief requires a trained model, one object per image, and that the model automatically decide which input controls what, on a free T4. We therefore asked: can a trained layer make SDXL enforce per-attribute responsibilities (text = identity, sketch = shape, reference = colour and material; where inputs conflict the reference wins colour), rather than only rescaling global strengths?

How the two LoRA attempts failed.

  • Fusion LoRA (attempt 2). A LoRA on the attention layers of the whole UNet, trained on 160 (target, sketch, reference, caption) quadruples with role dropout (full inputs 40%; greyscale reference 25%; caption colour words removed 25%; no conditions 10%), the real photo being the target. It did what the targets rewarded, resolving object conflicts 8/8 (baseline 2/8) with more realistic images, but because it had to reproduce the whole photo it learned the scene, and since it sits in the layers where the ControlNet residuals enter, it learned to ignore the sketch: edge IoU fell 0.369 → 0.230. The identity gain was bought with the shape role.
  • Role LoRA (attempt 6). To avoid that, we restricted the LoRA to where SDXL reads its inputs (text attn2 key/value, about 4.8 M parameters; IP-Adapter key/value, about 3.4 M; late blocks; rank 16), froze ControlNet, and trained on colour, material and hue-rotated conflict rows with loss = masked diffusion + 2× colour (decoded x0 on the object mask) + 0.5× texture + 0.5× preservation to the LoRA-off model. On 12 test photos it gave the highest edge IoU (0.753) but collapsed target similarity (DINO to target 0.359 → 0.057, CLIP-T 0.263 → 0.220) and lowered attribute compliance (colour 0.30, material 0.00, swapped reference 0.40, against 0.70, 0.67, 0.70 for the fixed baseline). The outputs followed the sketch but no longer resembled the photo, and the colour and material roles were not learned. Object-vs-sketch conflicts had no exact target and so no training rows, and with 160 training photos and one short run (no repeat seeds) we could not separate over-fitting from a wrong loss design. Neither LoRA was adopted.

Lesson. Detecting conflicts and rescaling global strengths does not enforce attribute-specific control, and trainable gates inside a frozen SDXL received too weak a signal. What moved the output was routing the text path including ControlNet's, so that the reference could supply colour.

3. ARL experiment and results

Setup. Held-out photo 0027, three conflict rows (object: “Black ape…” with an axe sketch; colour: caption “…black” vs brown leather reference; material: “…made of metal” vs leather), six arms, identical seed, 512 px, 20 steps, about 7 s per image on a T4. Colour/material hit = output matches the reference; edge IoU = sketch fidelity; DINO-ref = similarity to the reference image; CLIP-T = caption alignment. Controls: schedule-only (separates the router from the schedule) and flags forced to 1 (enforcement without the detector).

Findings. The ARL reaches the reference colour in 3 of 3 rows and the material in 2 of 3 (fixed: 1 of 3 and 2 of 3). The schedule-only control reaches the same colour score, so most of the colour gain comes from the schedule, not the learned router; the flag gate adds the material gain. The cost is sketch fidelity (edge IoU 0.059 vs 0.378), and the flag gate alone keeps the sketch (0.370) but rarely changes colour. No arm resolves the object conflict (the caption's ape is never produced).

4. Limitations and future work

  • The ARL result is a one-photo, three-row pilot; the 20-photo test split and the 800 conflict rows are not yet evaluated, and no confidence intervals are reported. Numbers for attempts 1–3 and 5–6 are taken from our run reports, not re-run for this report.
  • Future work (improving the architecture):
  • Attribute-specific routing: replace the four global scalars by independent, attribute-aware routing decisions, so identity, geometry, colour and material are controlled separately.
  • Disentangled reference conditioning: build reference representations that keep colour and material but suppress object identity and shape, removing the reference-object leakage seen in Section 2.
  • Spatially-aware conditioning: region-level masks and spatially adaptive gates change a conflicting attribute locally, so sketch-defined geometry (edge IoU) is not disrupted.
