Attribute Routing Layer

Text, sketch and reference image can disagree about one object. The ARL decides, per attribute, which input governs it, then conditions a frozen SDXL.

Recorded run, not live generation. SDXL needs a GPU, so this page replays the real pilot outputs: held-out photo 0027, 512 px, 20 steps on a T4, three conflict rows, one image per arm (n = 3 per arm, indicative only).

1. Pick a conflict

sketch → shapetext → identityreference → colour + material

2. What the ARL decided

Router settings chosen for this input

The router (trained MLP on six CLIP cosines) sets ControlNet scale, sketch hold time, IP-Adapter scale and guidance. The flag gate then blends the caption's colour or material word toward a neutral word by the flag value.

3. Compare the outputs

Summary over the three rows

The ARL reaches the reference colour in 3 of 3 rows, but sketch fidelity falls (edge IoU 0.059 against 0.378 for the fixed baseline). The schedule-only control reaches the same colour score, so most of the colour gain comes from the schedule, not the learned router. The object conflict is not resolved by any arm. In this pilot the governance network also misjudged two of three rows (step 2).
